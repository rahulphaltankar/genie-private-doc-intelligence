## Decision

This document records the founder's official signoff on the Genie versioning and distribution policy.

## Policy

| Scope | Policy |
|---|---|
| **v3 (Public)** | Sanitized and open — published publicly with all sensitive data removed |
| **v4+ (Private)** | Private by default — source code, models, and data remain proprietary |
| **Pilot Delivery** | Delivered exclusively as Docker containers or offline bundles — no raw source exposure |

## Rationale

- v3 serves as a reference/demo artifact for the community
- v4 introduces enterprise-grade features that are commercially sensitive
- Container/offline delivery protects IP while enabling client pilots without cloud dependency
